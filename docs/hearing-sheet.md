### トーン（1つ選ぶ）

- [ ] 写真風（実写に近い。リアルさ優先）

- [ ] 抽象グラフィック（具体物を描かない。光・粒子・幾何）
- [ ] 線画イラスト（細い線。図解寄り）

### 指定

- 出したい要素（例：オフィス、データ、握手、都市）：

## 提出方法

このシートを埋めて貼るか、プロジェクトファイルの該当部分をそのまま貼ってもらえれば、こちらで整理します。**フォーマットは崩れていて構いません。**

埋まった時点で、この順で進めます。

1. スライド構成案（何枚目に何を置くか）を先に出す → OKをもらう
2. HTML実装（グラフとインタラクションを含む）
3. Gemini用の画像プロンプト（10枚ずつ区切り／ファイル名と貼り込み位置つき）
4. 画像を受け取って貼り込み → 調整
