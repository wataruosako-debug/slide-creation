# AIインサイトセールス DL資料 構成案（20枚）

- 用途：LP/フォームからのDL、メール添付。対面説明なし
- 相手：中小企業の経営者（従業員5〜50名）。決裁権あり
- ゴール：オンライン説明会（無料）への申し込み
- 読了：3〜5分。**1枚あたり10〜15秒で意味が通ること**
- 地色：白基調／フラットベクターイラスト（濃紺の輪郭線・ベタ塗り）
- 納品：HTML（インタラクティブ）＋ PDF

---

## 全体の流れ

```
[掴む] 1-2        表紙・この資料で分かること
[問題] 3-7        なぜ止まるのか → 当てる先を外している
[解決] 8-13       AIインサイトセールスの中身
[証明] 14-16      ファネル・事例
[判断] 17-19      比較・進め方・FAQ
[行動] 20         説明会CTA
```

## インタラクションの入れどころ（HTML版のみ）

PDF版では静止画として成立する形で作り、HTML版だけ以下が動く。

| ページ | 動き |
|---|---|
| 6 | 前後の棒をホバーすると、コール数と件数を表示 |
| 11 | 500万件 → 業種 → 地域 → 規模 → 条件、と段階的に絞り込まれる |
| 12 | 3チャネルのカードをクリックすると詳細が開く |
| 14 | ファネルの各段でホバーすると通過率を表示 |
| 17 | 比較軸をクリックすると、その軸だけが強調される |
